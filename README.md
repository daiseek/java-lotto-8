# java-lotto-precourse

## 기능 요구 사항

1. 로또 번호의 범위는 1~45이다.

2. 1개 로또가 발행될 때는 중복되지 않는 6개 번호를 뽑는다.

- 당첨 번호 추첨 시 중복되지 않는 번호 6개와 보너스 번호 1개를 뽑는다.

3. 당첨은 1등부터 5등까지 있다. 당첨 기준과 당첨금은 아래와 같다.

- 1등 : 6개 번호 일치 & 2,000,000,000원
- 2등 : 5개 번호 일치 + 보너스 번호 일치 & 30,000,000원
- 3등 : 5개 번호 일치 & 1,500,000원
- 4등 : 4개 번호 일치 & 50,000원
- 5등 : 3개 번호 일치 & 5,000원

4. 로또 구입 금액을 입력하면 구입금만큼 로또를 발행해야 한다.

5. 로또 1장 가격은 1,000원이다.

6. 당첨 번호와 보너스 번호를 입력받아야 한다.

7. 사용자가 구매한 로또 번호와 당첨 번호를 비교해 당첨 내역과 수익률 출력 후 로또 게임을 종료한다.

8. 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException를 발생시킨다.
9. 이후 "[ERROR]"로 시작하는 에러 메시지 출력 후 그 부분부터 다시 입력 받는다.

- Exception이 아닌 IllegalArgumentException, IllegalStateException 등 같이 명확한 에러 유형으로 처리한다.

## 입출력 요구 사항

### 입력

1. 로또 구입 금액을 입력 받는다.
   구입 금액은 1,000원 단위로 입력 받으며 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.

```java
14000
```

2. 당첨 번호를 입력 받는다.
   번호는 쉼표(,)를 기준으로 구분한다.

```java
1,2,3,4,5,6
```

3. 보너스 번호를 입력 받는다.

```java
7
```

### 출력

1. 발행한 로또 수량 및 번호를 출력한다.
   로또 번호는 오름차순으로 정렬하여 보여준다.

```java
8개를 구매했습니다.
[8, 21, 23, 41, 42, 43]
[3, 5, 11, 16, 32, 38]
[7, 11, 16, 35, 36, 44]
[1, 8, 11, 31, 41, 42]
[13, 14, 16, 38, 42, 45]
[7, 11, 30, 40, 42, 43]
[2, 13, 22, 32, 38, 45]
[1, 3, 5, 14, 22, 45]
```

2. 당첨 내역을 출력한다.

```java
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
```

3. 수익률은 소수점 둘째 자리에서 반올림한다.
   (ex. 100.0%, 51.5%, 1,000,000.0%)

```java
총 수익률은 62.5%입니다.
```

4. 예외 상황 발생 시 에러 문구를 출력한다.
   에러 문구는 "[ERROR]"로 시작한다.

```java
[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
```

## 프로그래밍 요구 사항

프로그래밍 요구 사항1과 2는 이전과 비슷하다.
약간 추가된 내용을 다루자면,

1. 메서드 길이가 15줄을 넘지 않도록 한다.

- SRP를 지키도록 설계해라.

2. else 예약어를 사용하지 않는다. 추가로 switch/case 문도 사용하면 안된다.

- if문에서 return 값만 지정하는 방식으로 구현하면 굳이 else를 사용하지 않아도 된다.

3. Java Enum 클래스를 사용한다.

4. 구현한 기능에 대해 단위 테스트를 작성한다.

- 단, UI 로직은 제외한다.
- UI 로직 : System.out, System.in, Scanner

5. camp.nextstep.edu.missionutils 라이브러리를 이용해 기능을 구현한다.

- 임의의 값 추출은 camp.nextstep.edu.missionutils.Randoms의 pickUniqueNumbersInRange()를 활용한다.
- 사용자의 입력값을 받는 기능은 camp.nextstep.edu.missionutils.Console의 readLine()을 활용한다.

### 라이브러리 사용 예시

(1) 1에서 45 사이의 중복되지 않은 정수 6개 반환

```java
Randoms.pickUniqueNumbersInRange(1, 45, 6);
```

### Lotto 클래스 관련하여

미리 제공된 Lotto 클래스를 사용해야 한다.
Lotto 클래스에서 numbers 이외 필드(인스턴스 변수)를 추가할 수 없다.
또, numbers의 접근 제어자인 private도 변경할 수 없다.
단, Lotto의 패키지는 변경할 수 있다.

미리 제공된 Lotto 클래스는 아래와 같다.

```java
public class Lotto {
    private final List<Integer> numbers;

    public Lotto(List<Integer> numbers) {
        validate(numbers);
        this.numbers = numbers;
    }

    private void validate(List<Integer> numbers) {
        if (numbers.size() != 6) {
            throw new IllegalArgumentException("[ERROR] 로또 번호는 6개여야 합니다.");
        }
    }

    // TODO: 추가 기능 구현
}
```
